## Projects

### [Flylet](https://github.com/ItsMrZxD/Flylet)
Modern, Fluent-style replacements for the Windows volume, brightness, media and lock-key pop-ups. Live on the [Microsoft Store](https://apps.microsoft.com/detail/9NPSS6NW7T23), 31 languages, a maintained continuation of ModernFlyouts.

![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![release](https://img.shields.io/github/v/release/ItsMrZxD/Flylet?style=flat-square)
![CI](https://img.shields.io/github/actions/workflow/status/ItsMrZxD/Flylet/tests.yml?branch=main&style=flat-square&label=tests)

### [betaflight-blackbox-parser](https://github.com/ItsMrZxD/betaflight-blackbox-parser)
Reads the black-box flight recorder off an FPV drone and reports what happened: impacts, receiver dropouts, battery sag. Decodes Betaflight's binary log format from scratch, with zero dependencies.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![CI](https://img.shields.io/github/actions/workflow/status/ItsMrZxD/betaflight-blackbox-parser/ci.yml?branch=main&style=flat-square&label=CI)

### [fuzzy-entity-matching](https://github.com/ItsMrZxD/fuzzy-entity-matching)
Matches records across two CSV files even when names disagree (typos, abbreviations, word order) and scores each match 0-100 so you know which to trust.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
